# 🏥 Analítica de Costos e Ingresos Operativos en Salud (CRISP-DM)

Aplicativo web interactivo desarrollado para comparar el rendimiento financiero de los diferentes centros de costos y unidades funcionales de un hospital de primer nivel, orientando la toma de decisiones gerenciales hacia la sostenibilidad y un balance financiero positivo.

## 🎯 Enfoque Metodológico (CRISP-DM)
1. **Comprensión del Negocio:** Contrastar ingresos y costos operativos usando variables clave como `UNIDAD FUNCIONAL`, `C. COSTOS DETALLE` y `C. COSTOS ENCAB-EMISOR`.
2. **Modelo Predictivo:** Implementación de un algoritmo de **Random Forest Regressor** para estimar la facturación de nuevas atenciones según el centro de costos.
3. **Tablero Gerencial:** Visualización interactiva en Streamlit para identificar qué áreas generan mayor rentabilidad (hospitalización, laboratorio, farmacia, quirófanos).
